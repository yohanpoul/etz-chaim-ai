== THE FINDING (matters for ADR-0009 / DIRECTION) ==
Cheap single-shot Haiku elicitation has now failed on TWO task classes for TWO structural reasons:
  (i)  author-the-algorithm (balanced_brackets) -> a frontier model writes the CORRECT algorithm.
  (ii) choose-from-an-invented-library (datalib) -> a frontier model READS the short inlined source
       and picks the documented-correct function. An *invented, self-contained* library carries NO
       obsolete-API training prior to exploit (nothing "obsolete" exists in the model's weights).
Deeper point: the dead-end ADR-0009 actually cares about is a RE-ATTEMPT across context wipes
(does the agent re-commit a belief it already refuted), which only manifests in the MULTI-SESSION
loop — NOT in a single shot. A single-shot probe tests "make the mistake once"; the experiment tests
"re-make it after memory said no". The cheap single-shot gate may be structurally unable to surface
the very dead-end the full experiment is built around.
